# 场景自动切换 · 页面测试用例（agent.html）

> 日期：2026-10-11　被测页面：http://127.0.0.1:18901/agent.html
> 被测能力：**交互过程中由 agent 依据交互意图自动识别并切换「本轮配置」（场景）**
> 对应后端改动：`conversation_service.scene_for / scene_for_chart`、`turn_config_service.reload()`

---

## 0. 这份用例在验什么

以前「场景」是**会话级**的：建会话时按关键词猜一次，之后永不更新。
现在「场景」是**轮次级**的：每一轮由多轮 agent 读配置目录后判定，页面头部那颗
「本轮配置」胶囊显示的就是**这一轮实际加载的那套**。

要验的就是这条不变量：

> **同一会话里连着换话题，本轮配置要跟着换；画布上的动作（换一批维度 / 重跑某页 /
> 执行卡片 SQL）必须跟「本轮」用同一套配置，不能偷偷退回建会话时那套。**

> ✅ 关于「还要不要保留场景功能」：页面**从来没有手动场景选择器**，
> 现在也不需要有。场景已改为「本轮配置」胶囊，由 agent 自动判定，用户不用选。
> 页面上唯一可手动切换的是**模型档位**（右上角）。

### TC-1　单轮：一句话就能自动匹配到正确配置（冒烟）

| 项 | 内容 |

| 步骤 | 1. 打开 `agent.html`，点「新建会话」<br>2. 输入：**先看看纤维混纺的成分构成，出个图**　→ 发送 |

### TC-2　跨轮：换话题，本轮配置自动切换（核心）

| 项 | 内容 |
| --- | --- |
| 步骤 | 接 TC-1，**同一会话**不做任何其它操作，输入：**看看价格带的分布情况**　→ 发送 |
| 预期 | · 顶部胶囊**原地换成** **「本轮配置：商品价格分析（本轮按需加载）」**（不刷新页面、不新建会话）<br>· 新出的图卡是价格那套（价格带、价差……）<br>· 会话标题/历史消息都还在（还是同一个会话） |
| 判据 | 第 2 轮胶囊名称 ≠ 第 1 轮；第 2 轮取数用的是价格配置的字段 |
| 实测结果 | ✅ 通过（轮1 `scene_0004` → 轮2 `scene_prd_price`；会话级 scene_id 恒为 `scene_prd_competitor` 但**已不再被读**） |

> 这条是本功能验收的主用例。**关键**：会话级 `scene_id` 从头到尾没变过，
> 变的只是「本轮配置」——证明页面读的是**轮次**配置，不是会话级场景。

## 3.5　「配置」在页面上一共显示在哪三处

| 位置 | 显示什么 | 反映哪一轮 |
| --- | --- | --- |
| 顶部 **本轮配置** 胶囊（`#sceneChip`） | 本轮配置名 / 未加载原因 | **最后一轮** |
| 每条**回答**下的 **本轮配置** 小胶囊 | 同上 | **该条回答所属那一轮**（逐轮） |
| 画布**图卡**的 lineage | 该卡诞生时的 `config_ids`（`title` 悬浮可见） | **该卡创建时那一轮** |

三处口径一致（同一份 `turn_config` / `lineage`），所以不会出现
"顶部说价格、底下卡片却按纤维算"这种自相矛盾。

## 3.6　如果你现在就停在一屏「品牌需要确认」上，怎么测

截图里那屏的状态：头部「本轮配置：未加载（本轮不涉及配置）」，画布停着一张
**品牌确认卡**（「THE NORTH FACE」命中 2 个候选待确认），下面提示「该页没有可绘制的数值列」。

这不是 bug，是**上一步在等你确认**。两条路都可以走：

- **继续这条**：点那张卡上的候选，确认成你想看的品牌 → 它会接着取数、出图；
  出完图再看这**一条回答**下面的「本轮配置」胶囊，就是这次取数用的那套。
- **直接测场景切换**（推荐，最简单）：不用管那张卡，直接在输入框发
  **先看看纤维混纺的成分构成，出个图** → 看顶部胶囊是否变成「品牌商品纤维分析」，
  且**这条回答下面**也出现同一枚胶囊；紧接着再发 **看看价格带的分布情况** →
  顶部与这条回答下面都应变成「商品价格分析」。

> 注意：发「你好」这类闲聊，胶囊会显示「未加载（本轮不涉及配置）」——
> 那是**正确**的（闲聊本来就不该加载任何配置），不是失败。

## 4. API 复核（界面看不清指标时用）

全程 `--noproxy '*'`，前缀 `http://127.0.0.1:18900/api/v1/conversations`。

**建会话**
```bash
curl -s --noproxy '*' -X POST http://127.0.0.1:18900/api/v1/conversations \
  -H 'Content-Type: application/json' -d '{"title":"场景切换自测"}'
# 记下返回里的 conversation_id
```

**发一轮 / 看本轮配置**（`working_memory.turn_config` 就是胶囊的数据源）
```bash
CID=<上一步的 conversation_id>
curl -s --noproxy '*' -X POST .../conversations/$CID/messages \
  -H 'Content-Type: application/json' -d '{"text":"先看看纤维混纺的成分构成，出个图"}'
curl -s --noproxy '*' .../conversations/$CID \
  | python3 -c 'import sys,json;c=json.load(sys.stdin)["conversation"];print("会话级 scene_id =",c["scene_id"]);print("本轮 config_ids =",(c["working_memory"]["turn_config"]).get("config_ids"),(c["working_memory"]["turn_config"]).get("names"))'
```

**换一批维度**（看每个方向绑的指标）
```bash
curl -s --noproxy '*' -X POST .../conversations/$CID/dimensions/rotate \
  -H 'Content-Type: application/json' -d '{"exclude_keys":[]}' \
  | python3 -c 'import sys,json;[print(d["dimension_key"],"->",d["metrics"]) for d in json.load(sys.stdin)["dimensions"]]'
```

**执行某张旧卡**
```bash
curl -s --noproxy '*' -X POST .../conversations/$CID/artifacts/<artifact_id>/execute
```
