# 对话画布 · PPT 新操作流程

> 适用版本：2026-10-28 起（`agent.js?v=20261028-ppt-workbench-v5`）
> 入口：<http://127.0.0.1:18901/agent.html>

## 0. 起服务

双击 `~/Desktop/fz_workflow_restart.command`，要看到四行都 ok：


打开页面后 **Cmd+Shift+R 硬刷新一次**（资源版本升级过）。

## 1. 主流程：主题 → 大纲 → 确认 → 出稿

| 步 | 在哪儿做 | 要点 |
|---|---|---|
| 1 | 左栏聊天 | 先聊数据、出图，把要讲的东西聊出来（**不是必须**，见 1.1） |
| 2 | 左栏聊天 | 说「帮我串个 4 页左右的 PPT」→ 画布出 **「先定这份 PPT 的主题」卡**，**不搭页、不猜题** |
| 3 | 中间画布 · 汇报主题卡 | 写一句主题（会作为 PPT 标题与出稿依据）→ 点 **「生成大纲」** |
| 4 | 中间画布 · 汇报大纲卡 | 徽标 `待确认`；顶部 **主题** 可改；拖序号调页序 /「编辑内容」写要点与结论 /「新增一页」/「删除」 |
| 5 | 同上，或右侧工作台 | 点 **「确认大纲，生成 PPT」** |
| 6 | 顶栏 | 勾选 **「☑ PPT 模式」** → 最右侧出现 **PPT 工作台** |
| 7 | 右栏工作台 | 出稿后这里就是编辑器：改字、拖版式 |
| 8 | 右栏 | 在编辑器里点 **☰ →「同步到分析会话」**，回到左栏点 **「读回」** |

**主题已经在话里说了就不用走第 3 步**：说「做个《优衣库 2026 春夏竞品与价格复盘》的 PPT，4 页」，
agent 会把书名号里的内容原样当主题，直接出大纲（封面标题就是它）。

确认后徽标变 `已确认`，卡片按钮变 **「按大纲重新生成」**；再改大纲，PPT 会自动重排。
右栏头部还能 **导出 .pptx**。

## 1.1 从右侧工作台直接开始（一句话都不用先说）

勾选顶栏 **「PPT 模式」**，右侧就是一个 **工作台**，按状态显示三种形态：

| 当前状态 | 右栏显示 | 你能做什么 |
|---|---|---|
| 会话里还没有大纲 | **从主题开始做一份 PPT**：主题输入框 + 页数 + 「生成大纲」 | 写主题 → 生成大纲（等于替你在聊天里说了一句「帮我做一份《主题》的 PPT，N 页」） |
| 大纲有了、还没确认 | **当前主题 / N 页 · 待确认** + 「改主题重搭」「确认大纲，生成 PPT」 | 直接在这里确认出稿，不用折回中间画布 |
| 已经出稿 | 编辑器 | 改字、拖版式、导出 |

**大纲的页从哪来（重要）**：会话里已有的图表和结论只是**参考**，不是唯一来源。
主题点名了方向（如"价格"）→ 该方向排在最前面；没有现成图的页标「待取数」，
点「补齐待取数」会按当前配置的字段真去库里取数；页数不够再按配置里还没看过的方向补。

## 2. 常用说法（聊天里直接说）

| 你说 | 实际发生 |
|---|---|
| 帮我串个 4 页左右的 PPT | 问你要主题（出「汇报主题」卡），**不先替你搭页** |
| 做个《XX 复盘》的 PPT，4 页 | 主题已给 → 直接出大纲，`待确认`，不生成 PPT |
| 大纲压到 3 页 / 去掉色彩那页 | 改大纲；已确认的话 PPT 自动重排 |
| 把第 2 页改成「价格带结论」 | 整页替换 |
| **图2 换成折线图** | 按会话内编号找到第 2 张图，只改画法、不重跑数 |
| 只看 400 元以上的价格带 | 在当轮口径上加筛选并重跑 |
| 回退一下 | 大纲退回上一版 |
| 生成 PPT（还没确认时） | 被挡回来：提示先确认主题和大纲 |
| 生成 PPT（已确认后） | 重新出稿并刷新右栏 |

**图表编号**：每张图卡头部的蓝色 `图1 / 图2 / 图3` 是**会话内固定编号**，删掉一张不会让后面的图换号。
大纲页上也会标 `图1：面料成分与纤维混纺`，方便你对齐「第几页用第几张图」。

## 3. 已知边界

- **主题是用户给的，不是后端起的**：只说"做个 PPT"时它只会问主题，不会替你编一个
  「品牌 + 场景复盘」当标题（那会让你先改题再改页，白做一轮）。
- **没主题不能确认**：主题是出稿依据，输入框空着点确认会被拒。
- **页数不够只搭能落地的页**：素材只够 2 页却说 4 页时，如实搭 2 页并说明原因。
- **待取数页要真的取到数才有图**：大纲先按方向落页，点「补齐待取数」才去库里取；
  取不到会如实说哪几页没成，不会拿假数据凑。
- **老会话主题是空的**：本次升级前建的大纲没有主题，需要你填一次。
- **「把图2 挪到第3页」暂不支持**：重新绑页还没做，现在只能按编号换画法/加条件。
- **三栏很挤时先「收起」画布**：1280 宽下实测 聊天 400 / 画布 318 / 工作台 518；
  再窄就把画布收成窄条（点击「收起」），工作台才有地方改版式。

## 4. 出了问题时

| 现象 | 先看 |
|---|---|
| 右栏空 / 打不开 | `5173` 是否在跑；`tail -n 40 runtime_data/logs/ppt_editor.log` |
| 对话只回「服务不可用」 | `2124` 挂了：`bash scripts/start_deerflow_agent.sh` |
| 页面还是旧样子 | 硬刷新；确认 `agent.html` 里 `?v=20261028-ppt-workbench-v5` |
| 勾了 PPT 模式只有输入框 | 正常：还没有大纲，先写主题点「生成大纲」 |
| 画布只有「先定主题」卡 | 正常：主题还没给。写上主题点「生成大纲」即可 |
| 工作台显示「待确认」但没有编辑器 | 正常：确认大纲之后才出稿（点右栏那个「确认大纲，生成 PPT」） |
| 大纲改完 PPT 没变 | 先看是不是 `待确认`（没确认不会出稿） |
